Carte de calibration Lucens — mode d'emploi

Cette carte sert à calibrer la détection du Live View sur ta caméra et ta lampe UV.

  1. Imprime cette page sur du papier blanc épais (ou colle-la sur un carton rigide).
  2. Colorie chaque case avec le surligneur indiqué — remplis bien le rectangle.
  3. La case BLANC : ne touche à rien, laisse le papier blanc.
  4. La case NOIR : colorie-la avec un marqueur permanent noir.
  5. Découpe la carte le long du cadre noir.
  6. Dans l'app : LIVE → ⚙ → Calibrer, allume ta lampe UV, aligne la carte dans le cadre-guide, valide.

Surligneurs nécessaires : jaune fluo, vert fluo, bleu/cyan fluo, rose fluo (pack de 4-5 surligneurs, ~5 €).
