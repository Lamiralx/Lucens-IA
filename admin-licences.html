Sécurité · double authentification (2FA)

Renseignez le token pour voir l'état de la 2FA.

Le token seul ne suffit plus une fois la 2FA activée : il faudra aussi un code à 6 chiffres généré par Google Authenticator (ou Authy / 1Password) sur votre téléphone. Rien n'est lié à cet ordinateur.

1. Scannez ce QR code avec votre application d'authentification :

…ou saisissez cette clé manuellement (« Saisir une clé de configuration ») :

2. Entrez le code à 6 chiffres affiché par l'app pour confirmer :

Notez ces codes de secours MAINTENANT — ils ne seront plus jamais affichés. Chacun débloque l'accès une seule fois si vous perdez votre téléphone. Gardez-les en lieu sûr (gestionnaire de mots de passe, papier au coffre).

Pour transférer vers un nouveau téléphone : désactivez puis réactivez.
