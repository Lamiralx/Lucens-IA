Confidentialité

Vos données, en clair

Lucens analyse des photos prises sous lampe UV pour vous aider à repérer des traces d'hygiène. Cette page explique ce que devient chaque donnée : ce qui est utilisé, combien de temps, et comment tout faire supprimer.

L'essentiel
  • Votre photo sert à produire l'analyse, puis elle n'est pas conservée.
  • Votre historique d'inspections reste sur votre appareil. Il ne part jamais sur nos serveurs.
  • Pas de compte, pas de publicité, pas de traceur. Rien n'est revendu.
  • Vous pouvez faire supprimer vos données à tout moment, gratuitement.

Ce que Lucens utilise

Pour réaliser une analyse, Lucens traite :

  • la photo que vous envoyez ;
  • le résultat de l'analyse ;
  • le contexte que vous indiquez (type de lieu, secteur, moment de la prise de vue) ;
  • quelques informations techniques nécessaires au fonctionnement du service.

Et, uniquement si vous le décidez, les retours que vous envoyez via le bouton de feedback.

Vos photos ne sont pas gardées, sauf si vous le choisissez

Quand vous lancez une analyse, votre photo sert à produire le résultat, puis elle n'est pas conservée.

La seule exception : si, après une analyse, vous décidez d'envoyer un feedback correctif (une version réduite de l'image, avec vos annotations) pour nous aider à améliorer Lucens. Cet envoi est toujours un choix explicite de votre part. Il n'a jamais lieu tout seul.

Votre historique reste sur votre appareil

Les analyses que vous gardez sont enregistrées uniquement sur votre téléphone ou votre tablette. Elles ne sont pas envoyées sur nos serveurs et restent consultables même sans connexion.

Si vous désinstallez l'application ou videz les données du navigateur, cet historique est effacé définitivement. Pensez à exporter vos rapports importants avant.

Pas de compte, pas de pub, pas de traceur

Lucens fonctionne sans compte. L'application n'affiche aucune publicité et n'utilise aucun traceur publicitaire. Aucune donnée n'est vendue ni partagée à des fins commerciales.

Le feedback est optionnel

À la fin d'une analyse, vous pouvez nous dire si la détection était juste. C'est entièrement facultatif. Ces retours nous servent à :

  • améliorer la précision de Lucens ;
  • repérer les erreurs qui reviennent ;
  • tester la qualité des futures versions.

Aucune image n'est utilisée pour améliorer Lucens sans votre accord explicite.

Combien de temps c'est gardé

  • Les retours simples (une note, sans image) : regroupés, sans rien qui vous identifie. Nous les gardons pour suivre la qualité du service.
  • Les images correctives : 12 mois maximum, ou moins si vous demandez leur suppression avant.

Votre adresse IP n'est pas enregistrée avec ces retours. Une image peut être reliée à un repère technique qui ne contient pas votre nom. Cela limite fortement les risques, sans rendre les données totalement intraçables : c'est pourquoi le droit à l'oubli ci-dessous existe.

Ces traitements reposent sur votre accord (le feedback) et sur notre intérêt légitime à améliorer la détection.

Tout faire supprimer

Quand vous envoyez un feedback ou une image corrective, Lucens vous remet un code de suppression personnel.

  • Conservez ce code. C'est lui qui identifie vos données.
  • Pour tout faire effacer, transmettez-nous ce code (voir Nous contacter ci-dessous).
  • La suppression est gratuite, sans compte, et définitive.

Sans ce code, nous ne pouvons pas retrouver vos données avec certitude. Gardez-le en lieu sûr.

Ce que vous ne devez pas photographier

Pour protéger tout le monde, n'envoyez pas d'images montrant :

  • des personnes reconnaissables ou des badges ;
  • des documents confidentiels, des plans de site, des informations sur des clients ;
  • tout élément couvert par un secret professionnel ou industriel,

sauf si vous y êtes expressément autorisé.

Qui fait fonctionner Lucens

Pour fonctionner, Lucens s'appuie sur des prestataires techniques d'hébergement et d'analyse d'images. Ils sont encadrés par contrat et tenus à la confidentialité.

Vos photos d'analyse ne sont pas conservées par ces prestataires au-delà du traitement. La liste détaillée des prestataires est disponible sur demande (voir Nous contacter).

Ce que Lucens n'est pas

Lucens est une aide visuelle. Ce n'est pas un diagnostic microbiologique, chimique ou médical. Lucens ne prend aucune décision officielle à votre place.

La décision finale (valider une surface, libérer un produit, conclure sur l'hygiène) reste toujours humaine. Elle doit être confirmée par les méthodes de terrain appropriées : ATP-métrie, écouvillonnages, analyses de laboratoire, contrôles HACCP.

Nous contacter

Pour toute question sur vos données, pour obtenir la liste des prestataires ou pour faire effacer un feedback, utilisez le formulaire de retour intégré à l'application (proposé après chaque analyse) et joignez votre code de suppression à votre message. Votre demande est traitée gratuitement.
