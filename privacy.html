Vos données, en clair

Lucens analyse des photos prises sous lampe UV pour vous aider à repérer des traces d'hygiène. Cette page explique simplement quelles données sont utilisées, combien de temps elles sont gardées, et comment tout faire supprimer, sans jargon.

L'essentiel
  • Votre photo sert à produire votre analyse, puis elle n'est pas conservée.
  • Vous ne partagez une image que si vous le décidez vous-même. Jamais automatiquement.
  • Vous pouvez faire supprimer vos données à tout moment, gratuitement et sans créer de compte.

Ce que Lucens utilise

Pour réaliser une analyse, Lucens traite :

  • la photo que vous envoyez ;
  • le résultat produit par l'analyse Lucens IA ;
  • le contexte que vous indiquez (type de lieu, secteur, moment de la prise de vue) ;
  • quelques informations techniques nécessaires au bon fonctionnement du service.

Et, uniquement si vous le faites volontairement, les retours que vous nous envoyez via le bouton de feedback.

Vos photos ne sont pas gardées, sauf si vous le choisissez

Quand vous lancez une analyse, votre photo sert à produire le résultat, puis elle n'est pas conservée.

La seule exception : si, après une analyse, vous décidez d'envoyer un feedback correctif (une version réduite de l'image accompagnée de vos annotations) pour nous aider à améliorer Lucens. Cet envoi est toujours un choix explicite de votre part ; il n'a jamais lieu tout seul.

Le feedback est optionnel

À la fin d'une analyse, vous pouvez nous dire si la détection était juste. C'est entièrement facultatif. Ces retours nous servent à :

  • améliorer la précision de Lucens ;
  • repérer les erreurs qui reviennent ;
  • tester la qualité des futures versions.

Aucune image n'est utilisée pour améliorer Lucens sans votre accord explicite.

Combien de temps les données sont gardées

  • Les retours simples (une note, sans image) : conservés sous forme groupée et anonymisée.
  • Les images correctives : 12 mois maximum, ou moins si vous demandez leur suppression avant.

Lucens n'enregistre pas volontairement votre adresse IP avec ces retours. Une image peut être reliée à un identifiant technique anonyme. Cela limite fortement les risques, mais ne rend pas les données totalement intraçables : c'est pourquoi le droit à l'oubli ci-dessous existe.

Votre droit à l'oubli, tout faire supprimer

Dès que vous envoyez un feedback ou une image corrective, Lucens vous remet un code de suppression personnel, à usage unique.

  • Conservez ce code. C'est lui qui identifie vos données.
  • Pour faire effacer les données liées, transmettez-nous ce code (voir Nous contacter ci-dessous).
  • La suppression est gratuite, ne demande aucun compte, et est définitive.

Sans ce code, nous ne pouvons pas garantir de retrouver précisément vos données parmi les autres. Gardez-le donc en lieu sûr.

Ce que vous ne devez pas photographier

Pour protéger tout le monde, n'envoyez pas d'images montrant :

  • des personnes reconnaissables ou des badges ;
  • des documents confidentiels, des plans de site, des informations sur des clients ;
  • tout élément couvert par un secret professionnel ou industriel,

sauf si vous y êtes expressément autorisé.

Qui traite vos données

Lucens s'appuie sur deux prestataires techniques :

  • Vercel : hébergement du site et stockage ;
  • Anthropic : analyse des images par Lucens IA.

Ils n'interviennent que pour faire fonctionner le service, le sécuriser et en améliorer la qualité. L'accès aux cas annotés et aux statistiques internes est réservé aux administrateurs autorisés, et les suppressions sont journalisées pour la traçabilité.

Ce que Lucens n'est pas

Lucens est une aide visuelle. Ce n'est pas un diagnostic microbiologique, chimique ou médical, et ce n'est pas une décision réglementaire automatisée.

La décision finale (valider une surface, libérer un produit, conclure sur l'hygiène) reste toujours humaine. Elle doit être confirmée par les méthodes de terrain appropriées : ATP-métrie, écouvillonnages, analyses de laboratoire accréditées, contrôles HACCP.

Nous contacter

Pour toute question sur vos données, ou pour faire supprimer un feedback, écrivez à l'équipe Lucens à l'adresse de contact indiquée sur le site. Si vous avez un code de suppression, joignez-le à votre message.
