Activité par semaine

Active learning — Top 20 à annoter

Cas priorisés via Core-Set (Sener & Savarese 2018) : uncertainty × surprise + clustering K-Means pour la diversité.

Calibration de la confidence Claude

Reliability diagram + ECE/MCE via Isotonic Regression PAV (Guo et al. 2017). Détecte si la confidence du modèle est fiable.

Optimisation des seuils HSL

Grid search sur les seuils heuristiques côté client. Maximise F1 sur le dataset feedback.

A/B testing du prompt

Allocation déterministe par hash + Z-test 2 proportions. Promote auto si gain significatif, rollback si guardrail violé.

Accord inter-annotateurs

Cohen Kappa par paire d'annotateurs + agrégation Dawid-Skene des labels. Détecte les images litigieuses qui méritent arbitrage manuel.
