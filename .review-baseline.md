# Lucens IA — baseline pour /ultrareview

Cette branche `main` est volontairement vide.

Le code complet de production (état V37 au 2026-05-24) se trouve sur la
branche [`v37`](https://github.com/EasyReportGen/lucens-ia/tree/v37).

Cette configuration permet à `/ultrareview` (et tout autre outil de PR
review qui diffuse un diff contre `main`) de reviewer **l'intégralité du
code V37** en une seule passe — chaque fichier de `v37` apparaît comme
ajouté.

## Branches

- **`main`** — baseline vide (ce fichier uniquement)
- **`v37`** — code complet déployé en production
  - 97 fichiers (~46 k lignes)
  - PWA HACCP UV-A 365 nm fluorescence
  - Live demo : <https://analyse-uv.vercel.app>

## Reprendre un workflow normal

Quand l'audit est terminé, fast-forward `main` sur `v37` :

```bash
git checkout main
git merge v37 --ff-only
git push origin main
```

Puis rebascule le repo en privé :

```bash
gh repo edit EasyReportGen/lucens-ia --visibility private --accept-visibility-change-consequences
```
